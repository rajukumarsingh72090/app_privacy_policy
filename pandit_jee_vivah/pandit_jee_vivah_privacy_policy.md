## 6. Data Security Measures

- **Encryption in Transit:** All traffic is secured using TLS 1.3 / HTTPS with 256-bit encryption.
- **Password Protection:** Passwords are never saved in plain text; they are hashed using salted bcrypt.
- **Session Security:** Short-lived JSON Web Tokens (JWT) with secure storage.
- **Bytecode Obfuscation:** The Android binary is compiled using Google R8 Pro full-mode optimization and ProGuard keep rules.
