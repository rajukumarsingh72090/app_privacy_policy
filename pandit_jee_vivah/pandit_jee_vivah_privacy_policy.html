6. Data Security & Storage Architecture

We employ multi-layer security protocols to safeguard your personal matrimonial data:

  • 256-Bit TLS Encryption: All data transmitted between your device and our servers is encrypted using modern Transport Layer Security (TLS 1.3 / HTTPS).
  • Salted Cryptographic Hashing: User passwords are never saved in plain text. They are hashed using salted bcrypt prior to database storage.
  • Tokenized Authentication: Sessions are managed via short-lived JSON Web Tokens (JWT) and secure HTTP headers.
  • Code Obfuscation (R8 Pro): The Android application binary is compiled with Google R8 Pro full-mode optimization and ProGuard rules to prevent reverse engineering and unauthorized tampering.
